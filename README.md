# Tic-Tac-Toe Game

## About the Project

This is a simple and interactive Tic-Tac-Toe game developed using:

- HTML
- CSS
- JavaScript

The game is designed for two players. Players take turns placing X and O on a 3 × 3 board.

## Features

- Two-player game
- Player turn indication
- Winner detection
- Draw detection
- New Game button
- Simple and user-friendly interface

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Start playing the game.

## How to Play

1. Player X starts the game.
2. Players take turns clicking an empty box.
3. The player who gets three same symbols in a row wins.
4. Three symbols can be placed horizontally, vertically, or diagonally.
5. If all boxes are filled and nobody wins, the game is a draw.
6. Click the **New Game** button to play again.
